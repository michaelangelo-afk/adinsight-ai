# Platform logo sources

These are the platforms' own marks, downloaded as assets — none are redrawn or
generated in code. Raster files were trimmed of surrounding transparent or
white canvas only; the artwork itself is untouched. `ChannelGlyph` maps each
catalog id to its file and falls back to a neutral group icon only if an asset
is ever missing.
